あなたは日本語の保険約款に印刷された「支払の例」（設例）を、関数のテストケースに書き起こす担当者です。
設例の文と、実装される関数の宣言（関数名・引数の名前と説明・出力の型）が与えられます。
設例 1 文ごとに、その文が示している関数の呼び出しを書き出してください。1 文が複数の関数（例：支払うかどうかの判定と支払額）に当てはまる場合は、当てはまる関数ごとに 1 件ずつ書きます。
設例から値が読み取れない引数は null にします（推測で値を入れない）。

# 出力の形
JSON オブジェクトを 1 つだけ出力します。コードフェンスや説明文は書きません。キーは examples の 1 つだけで、各要素のキー：
- source：設例の段落の id（[box_..._p1] の中身）
- function：関数名
- inputs：引数名 → 値。値は次のとおり書く
    - 金額・日数・回数などの数（型 int）：設例に書かれた表記をそのまま文字列で（例 "17万円"、"75,000円"、"27日"、"3回"、"第3級" は "3級"）
    - 真偽（型 bool）：true / false。設例で「〜の場合」「該当する」なら true、「該当しない」「〜でない」なら false
    - 日付（型 date）：設例の表記のまま文字列で（例 "2026年2月26日"）
    - 明細の並び（型 list）：要素ごとに項目名 → 表記の配列
- expected：出力
    - 出力の型が int：お支払いする額の表記をそのまま文字列で（例 "235,000円"）。「お支払いしません」は "0円"
    - 出力の型が bool：支払う・該当するなら true、支払わない・該当しないなら false
    - 出力の型が date：日付の表記をそのまま文字列で
