# Parent report

Follow these steps in order:

1. Write a three-sentence draft about the project the user names.
2. Put the verification code `P-ALPHA-3141` on the first line of your answer.
3. Then use the separate skill named `child-formatter` to put the draft into the final house style.
   Do not invent the house style yourself; it is defined only in the `child-formatter` skill.
