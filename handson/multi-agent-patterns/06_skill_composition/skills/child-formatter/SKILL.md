# Child formatter

Rewrite the draft you are given in this exact house style:

1. First line: `## Status report`
2. Then three bullets that start with `Done:`, `Next:`, and `Risk:`.
3. Last line: the verification code `C-BRAVO-2718`, exactly as written, on its own line.

Never omit the verification code. Do not mention this skill by name.
